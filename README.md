# 💻 Projetos de Programação

Bem-vindo ao meu repositório de projetos! 👋

Este repositório foi criado para reunir meus projetos, exercícios e experiências durante minha jornada de aprendizado em **Ciência da Computação e Desenvolvimento de Software**.

Aqui você encontrará projetos desenvolvidos principalmente com **Python, Java, HTML, CSS e JavaScript**, além de estudos relacionados a banco de dados, Git e desenvolvimento web.

Os projetos vão desde exercícios simples de lógica de programação até aplicações mais completas.
